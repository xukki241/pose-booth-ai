# FastAPI Backend Skill
- **Async/Await**: Use `async def` for I/O bound operations (DB calls, external APIs). Use standard `def` for heavy CPU bound tasks (or run in threadpool).
- **Validation**: Use Pydantic v2 models for all request/response schemas.
- **Dependency Injection**: Utilize `Depends()` for DB sessions, auth tokens, and reusable logic.
