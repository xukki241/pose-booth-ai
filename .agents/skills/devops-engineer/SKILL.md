# DevOps Engineer Skill
- **Docker**: Write multi-stage Dockerfiles to minimize image size. Never run containers as root.
- **CI/CD**: Automate linting, testing, and building via GitHub Actions or GitLab CI.
- **Observability**: Ensure proper structured logging and healthcheck endpoints (`/health`).
