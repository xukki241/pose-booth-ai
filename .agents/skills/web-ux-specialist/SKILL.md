# Web UX Specialist Skill
- **Touch Targets**: Ensure interactive elements are at least 44x44px for mobile.
- **Perceived Performance**: Use skeleton screens and optimistic UI updates.
- **Feedback**: Provide immediate visual feedback for all user actions (hover states, active states, loaders).
