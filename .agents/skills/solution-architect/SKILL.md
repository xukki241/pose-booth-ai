# Solution Architecture Skill
- **Diagramming**: Use Mermaid `flowchart` or `sequenceDiagram` to visualize architecture.
- **Trade-offs**: Always document trade-offs (e.g., Latency vs. Throughput, Consistency vs. Availability).
- **Contracts**: Design API contracts before implementation.
