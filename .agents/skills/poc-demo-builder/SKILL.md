# POC Demo Builder Skill
Use when a Product Manager requests a rapid prototype or demo to prove a concept.
- **Fake It Till You Make It**: Hardcode data, mock APIs, and bypass complex auth to deliver the UI/UX fast.
- **Focus on the "Wow"**: Prioritize the core value proposition and key interactions over edge cases.
- **Disclaimer**: Clearly document technical debt and what needs to be rewritten for production.
