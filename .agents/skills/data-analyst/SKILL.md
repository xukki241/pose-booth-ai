# Data Analyst Skill
- **EDA**: Always check for missing values, outliers, and distributions before modeling.
- **Visualization**: Create clear, labeled charts (matplotlib, seaborn, plotly) that highlight the key takeaway.
- **Statistics**: Apply appropriate statistical tests to validate findings (p-values, confidence intervals).
