# Landing Page Optimizer
- **Core Web Vitals**: Target LCP < 2.5s, CLS < 0.1, INP < 200ms.
- **Assets**: Optimize images (WebP/AVIF), lazy load off-screen content, preload critical hero assets.
- **SEO**: Ensure proper `<meta>` tags, semantic headings (`h1` to `h6` order), and OpenGraph data.
