# Frontend Designer Skill
Use when implementing UI components, layouts, or styling.
- **Tailwind**: Use utility classes efficiently. Prefer `cn()` utility for conditional classes.
- **Accessibility (a11y)**: Ensure proper `aria-*` tags, keyboard navigability, and sufficient color contrast.
- **Responsive**: Design mobile-first using `sm:`, `md:`, `lg:` prefixes.
